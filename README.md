# Quote of the Day — Angular 21 + Bootstrap 5.3.8

A lightweight, modern Angular application that fetches and displays an inspirational quote with a clean Bootstrap UI. Includes a loading state, a polished card layout, and a one‑click Tweet button.

## Features

- Angular 21 standalone application
- Bootstrap 5.3.8 responsive UI
- Fetches a new quote on demand
- Loading spinner while retrieving data
- Clean card layout with author attribution
- One‑click “Tweet This” sharing
- Prettier formatting for Angular templates

## Installation

```bash
git clone https://github.com/iNoles/quote-day-angular
cd quote-day-angular
npm install
```

### Running the App

Start the development server:
```bash
ng serve
```

Then open:
```
http://localhost:4200
```

### Building The App

To build the project run:

```bash
ng build
```

This will compile your project and store the build artifacts in the `dist/` directory. By default, the production build optimizes your application for performance and speed.
